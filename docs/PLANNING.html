DC6
Effects & Plugin Hosting v0.6.0 Planned
10 built-in DSP audio effects, effect chain processing, effects rack UI, and external plugin hosting framework.
Built-in DSP Effects (10)
  • ParametricEQ — 10-band parametric equalizer (RBJ biquad filters)
  • GraphicEQ31 — 31-band graphic equalizer (ISO 1/3-octave centers)
  • Compressor — dynamics processor with threshold, ratio, attack, release, knee
  • Limiter — look-ahead brick-wall limiter for true peak prevention
  • NoiseGate — gate with threshold, hold time, and range control
  • DeEsser — sibilance reduction with frequency-selective compression
  • AGC — automatic gain control for broadcast-consistent levels
  • Reverb — algorithmic reverb with room size, damping, wet/dry
  • SonicEnhancer — BBE-style psychoacoustic enhancement (3-band LR4)
  • Normalizer — peak and LUFS normalization with target level
Plugin Architecture
  • DSP chain — ordered effect inserts per track with bypass toggle
  • Effects rack widget — drag-and-drop reorder, enable/disable
  • IEffectUnit interface — process(), reset(), parameterCount(), etc.
  • IPlugin interface — dynamic library loading framework
  • Float64 internal processing for maximum precision
  • Latency compensation — automatic delay across effect chains
  • YAML preset save/load for all effect parameters

  • DipToBlack — fade out to black, then fade in

  • WipeLeft — horizontal wipe reveal from right to left
  • PushSlide — new clip pushes old clip off screen
  • ZoomThrough — zoom into clip A, emerge from clip B

  • LumaKey — luminance-based transparency keying
  • GlitchCut — digital glitch effect with block displacement
