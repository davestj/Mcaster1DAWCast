Overview

Mcaster1DAWCast is a broadcast-grade digital audio workstation (DAW) built with C++17 and Qt 6. It combines multi-track audio editing, video compositing, live broadcast streaming, and podcast production into a single integrated application. DAWCast serves as the creative production centerpiece of the Mcaster1 broadcast ecosystem, working alongside Mcaster1AMP (media player), Mcaster1AudioPipe (virtual audio routing), and Mcaster1DSPEncoder (broadcast encoding).

What It Does

  • Multi-track audio recording, editing, and mixing with non-destructive workflow
  • Video track compositing with 10 transitions, subtitles, and broadcast graphics
  • Live broadcast output to Icecast, Mcaster1DNAS, and RTMP servers
  • Podcast production with chapter markers, RSS generation, and loudness normalization
  • 10 built-in DSP effects (EQ, compressor, limiter, reverb, de-esser, and more)
  • YAML-driven theme engine with hot-swappable theme packs
  • Cross-platform (macOS, Windows, Linux) via autotools + Qt 6
ℹ
Ecosystem Role. DAWCast is the production studio where content is created and mixed. It routes audio through Mcaster1AudioPipe virtual devices for zero-latency inter-app routing, and can stream directly to broadcast servers via Mcaster1DSPEncoder or its built-in stream encoder.

Architecture

Mcaster1DAWCast uses a modular architecture with clearly separated engine layers. The core modules communicate through a module registry that supports dynamic discovery and loading. All audio processing runs on a dedicated real-time thread managed by PortAudio, while video decoding and broadcast encoding run on separate worker threads.

Module Diagram

Mcaster1DAWCast | +--- core/ // Foundation layer | +--- ModuleRegistry // Dynamic module discovery & loading | +--- ProjectManager // Project file I/O (.dawcast JSON) | +--- UndoManager // Command-pattern undo/redo stack | +--- IModule / IPlugin // Abstract interfaces for extensibility | +--- IEffectUnit // DSP effect interface (process, reset, params) | +--- IVideoEffect // Video transition interface | +--- audio_engine/ // Real-time audio processing | +--- AudioEngine // PortAudio callback, device management | +--- AudioMixer // Summing bus, per-track gain/pan | +--- AudioWorker // Worker thread for disk I/O + decode | +--- AudioResampler // Sample rate conversion (SRC) | +--- RingBuffer // Lock-free SPSC for RT thread decoupling | +--- video_engine/ // Video processing | +--- VideoDecoder // FFmpeg decode (HW accel) | +--- VideoEncoder // FFmpeg encode (H.264/265, VP9, AV1) | +--- VideoMixer // Layer compositing with blend modes | +--- VideoRenderer // QWidget-based preview output | +--- SubtitleRenderer // SRT / ASS / VTT rendering | +--- MuxerDemuxer // Container handling (MP4, MKV, WebM) | +--- dsp/ // Audio effects library (10 effects) | +--- DspChain // Ordered effect chain per track | +--- ParametricEQ // 10-band RBJ biquad EQ | +--- Compressor // Dynamics processor | +--- Limiter // Look-ahead brick-wall limiter | +--- Reverb, AGC, ... // Additional processors | +--- vfx/ // Video effects & transitions (10) +--- broadcast/ // Live streaming (Icecast, DNAS, RTMP) +--- podcast/ // Chapters, RSS, metadata, export +--- graphics/ // Broadcast overlays (lower thirds, ticker) +--- timeline/ // Tracks, clips, regions, automation +--- widgets/ // Qt6 UI components +--- codec/ // Audio codec registry (WAV, FLAC, MP3, AAC...) +--- config/ // AppConfig, debug logger, YAML presets +--- platform/ // OS-specific (macOS, Windows, Linux)

Thread Model

Four-Thread Architecture

Thread Priority Responsibility Communication
RT Audio Real-time PortAudio callback, audio mixing, DSP chain processing, ring buffer read/write Lock-free SPSC ring buffers, atomic flags
UI Thread Normal Qt6 event loop, widget rendering, user interaction, timeline display Qt signals/slots, queued connections to audio thread
Video Decode Normal FFmpeg decode, frame scaling, subtitle rendering, transition compositing Thread-safe frame queue, condition variables
Broadcast Above normal Stream encoding (MP3/AAC/Opus), Icecast/DNAS/RTMP output, ICY metadata SPSC buffer from master bus, atomic state flags

Getting Started

Prerequisites

Required Dependencies

  • C++17 compiler — GCC 9+, Clang 10+, or MSVC 2019+
  • Qt 6 — Widgets, SVG, Multimedia modules
  • PortAudio — Cross-platform audio I/O library
  • FFmpeg — libavcodec, libavformat, libavutil, libswscale, libswresample
  • libsamplerate — High-quality sample rate conversion
  • yaml-cpp — YAML configuration parsing
  • nlohmann-json — JSON project file I/O
  • libmp3lame — MP3 encoding
  • libvorbis / libogg — Vorbis encoding/decoding
  • libopus — Opus encoding/decoding
  • libflac — FLAC encoding/decoding
  • fdk-aac — AAC encoding (optional, license-restricted)

Quick Start

# Clone and build
cd ~/dev/01_mcaster1.com/Mcaster1DAWCast
./autogen.sh
./configure
make -j$(nproc)

# Run
./src/DAWCast/mcaster1dawcast

First Project

After launching, DAWCast opens with an empty project. Use File → New Project to create a new session, or File → Open to load an existing .dawcast project file. Import audio/video via the Media Browser or drag files directly onto the timeline.

Audio Pipeline

The audio pipeline is built on PortAudio for cross-platform audio I/O. The real-time callback processes audio in fixed-size buffers (typically 256–1024 frames), reading from track clips, applying DSP chains, and mixing to the master bus. A lock-free SPSC ring buffer decouples the real-time audio thread from the UI and disk I/O threads.

PortAudio Callback Flow

PortAudio callback (RT thread, ~5ms period at 48kHz/256 frames) | +--- 1. Read audio clips | Each AudioTrack reads its active clip region into a buffer. | Clips reference source files via offset + length (non-destructive). | +--- 2. Apply DSP chain | Per-track DspChain processes audio through ordered effect inserts. | Effects: EQ, Compressor, Limiter, Gate, DeEsser, AGC, Reverb, etc. | Float64 internal precision, bypass toggle per effect. | +--- 3. Mix to buses | AudioMixer sums all tracks with per-track gain + pan. | Auxiliary sends route to aux buses (pre/post-fader). | Master bus applies final limiter. | +--- 4. Output Master bus writes to PortAudio output buffer (speakers/headphones). Simultaneously feeds SPSC ring buffer for broadcast encoder. Optionally routes to Mcaster1AudioPipe virtual device.

SPSC Ring Buffer

The RingBuffer class provides a lock-free single-producer single-consumer circular buffer using C++17 std::atomic with memory_order_acquire / memory_order_release semantics. The RT audio thread writes mixed output; the broadcast encoder thread reads it. No mutexes, no system calls, no priority inversion.

✓
Real-time safe. The audio callback never allocates memory, never locks a mutex, and never performs disk I/O. Audio data is pre-loaded by the AudioWorker thread into per-clip buffers. The callback only reads, mixes, and writes — all bounded-time operations.

Video Pipeline

Video processing is powered by FFmpeg (libav*). The decoder runs on a dedicated thread, feeding decoded frames into a thread-safe queue. The video mixer composites multiple layers with opacity and blend modes, while the subtitle renderer overlays SRT/ASS/VTT text. During export or live broadcast, the encoder writes frames to container files or streams.

Video Processing Chain

VideoDecoder // FFmpeg avcodec decode (HW: VideoToolbox / VAAPI / DXVA2) | v VideoTrack clips // Timeline clips with in/out points, playback rate | v VideoEffectChain // CrossDissolve, DipToBlack, ChromaKey, WipeLeft, etc. | v VideoMixer // Layer compositing (opacity, blend modes) | +---> SubtitleRenderer // SRT, ASS/SSA, VTT overlay +---> GraphicsRenderer // Lower thirds, ticker, watermarks | +---> VideoRenderer // Qt widget preview display +---> VideoEncoder // H.264, H.265, VP9, AV1 via FFmpeg | v MuxerDemuxer // MP4, MKV, WebM, MOV container output

Hardware Acceleration

Video decoding uses hardware acceleration when available: VideoToolbox on macOS, VAAPI on Linux, and DXVA2 on Windows. The platform abstraction layer in platform/macos_video.h manages device selection. Hardware acceleration is optional — the decoder falls back to software (libavcodec) automatically.

Effects & DSP

DAWCast includes 10 built-in audio effects and 10 video transitions. All audio effects implement the IEffectUnit interface and process audio in Float64 precision. Video transitions implement the IVideoEffect interface.

Audio Effects (10)

Effect Class Description
Parametric EQ ParametricEQ 10-band parametric equalizer using RBJ biquad filter coefficients. Adjustable frequency, gain, and Q per band.
31-Band Graphic EQ GraphicEQ31 31-band graphic equalizer at ISO 1/3-octave center frequencies (20 Hz – 20 kHz).
Compressor Compressor Dynamics processor with adjustable threshold, ratio, attack, release, and soft knee.
Limiter Limiter Look-ahead brick-wall limiter for true peak prevention. Broadcast-safe output ceiling.
Noise Gate NoiseGate Gate with threshold, hold time, and range control. Eliminates background noise between speech.
De-Esser DeEsser Sibilance reduction via frequency-selective dynamic compression (4–8 kHz band).
AGC AGC Automatic gain control for broadcast-consistent output levels. Slow attack, medium release.
Reverb Reverb Algorithmic reverb with room size, damping, pre-delay, and wet/dry mix controls.
Sonic Enhancer SonicEnhancer BBE-style psychoacoustic enhancement using 3-band Linkwitz-Riley crossover with phase delay correction.
Normalizer Normalizer Peak and LUFS normalization to target level (e.g., -16 LUFS for Apple Podcasts, -14 LUFS for Spotify).

Video Transitions (10)

Transition Class Description
Cross Dissolve CrossDissolve Smooth opacity cross-fade between two clips. The most common video transition.
Dip to Black DipToBlack Fade out to solid black, then fade in to the next clip. Classic dramatic cut.
Dip to White DipToWhite Fade out to solid white, then fade in. Flash/dream sequence effect.
Wipe Left WipeLeft Horizontal wipe reveal from right to left with adjustable edge softness.
Push Slide PushSlide New clip pushes old clip off screen. Configurable direction (L/R/U/D).
Zoom Through ZoomThrough Zoom into clip A, emerge from clip B. Dynamic camera-style transition.
Chroma Key ChromaKey Green/blue screen removal with spill suppression and edge feathering.
Luma Key LumaKey Luminance-based transparency keying. Remove dark or light areas from foreground.
Glitch Cut GlitchCut Digital glitch effect with block displacement, color channel shift, and scan lines.
Stinger Overlay StingerOverlay Animated overlay transition for broadcast. Plays a stinger video clip over the cut point.

Broadcasting

DAWCast can stream live audio and video to Icecast2, Mcaster1DNAS, and RTMP servers. The built-in stream encoder runs on a dedicated thread, reading from the master bus ring buffer and encoding in real-time. ICY metadata (track title, artist) is pushed automatically as content changes.

Icecast / DNAS Integration

  • Protocol: HTTP source client (Icecast2 protocol) and Mcaster1DNAS native protocol
  • Codecs: MP3, Ogg Vorbis, Opus, AAC
  • Metadata: ICY inline metadata with configurable update interval
  • Multi-server: Simultaneous broadcast to up to 4 destinations
  • Reconnect: Automatic reconnection on network failure with exponential backoff
  • Archive: Simultaneous local recording of broadcast stream

RTMP Live Streaming

  • Targets: YouTube Live, Twitch, Facebook Live, custom RTMP servers
  • Video: H.264 encoding via FFmpeg with configurable bitrate and keyframe interval
  • Audio: AAC encoding at 128–320 kbps
  • Graphics: Lower thirds, ticker crawl, and watermarks composited into output

Broadcast Widgets

  • Tally Light: ON AIR (red), STANDBY (yellow), OFF (dim) status indicator
  • Broadcast Clock: Elapsed time, segment timers, countdown to next event
  • Live Recorder: Archive the broadcast to a local file (WAV, FLAC, or MP3)

Podcasting

DAWCast provides a complete podcast production workflow from recording to publishing. The podcast module handles chapter markers, RSS feed generation, metadata embedding, show notes authoring, loudness metering, and one-click export.

📖

Chapter Markers

Add, edit, and delete chapter markers with titles, URLs, and artwork. Chapters are embedded in MP3 (ID3v2 CHAP/CTOC) and M4A on export.

📡

RSS Feed Generator

Generates iTunes/Apple Podcasts-compatible RSS XML with episode metadata, enclosures, artwork, and categories.

🎵

Loudness Metering

LUFS measurement per ITU-R BS.1770-4. Target -16 LUFS (Apple Podcasts) or -14 LUFS (Spotify) with auto-normalization.

📝

Show Notes Editor

Rich text show notes with HTML export. Links, timestamps, guest info, and sponsor sections.

📦

Podcast Exporter

One-click render to MP3 or AAC with chapters, metadata, artwork, and loudness normalization applied.

✍

Metadata Editor

Edit title, description, author, artwork, categories, and episode type (full, trailer, bonus).

Theme Engine

DAWCast includes a YAML-driven theme engine that supports hot-swappable theme packs. Each theme is a directory containing a theme.yaml configuration file and a style.qss Qt stylesheet. The theme engine reads YAML variables and performs string substitution into the QSS template, enabling dynamic color and style changes without recompilation.

Theme Pack Structure

themes/
  Default/
    theme.yaml          # Theme name, author, color variables
    style.qss           # Qt stylesheet with {{variable}} placeholders
  DarkStudio/
    theme.yaml
    style.qss
  BroadcastPro/
    theme.yaml
    style.qss

Included Themes

Theme Style Description
Default Light/neutral Clean, neutral color palette suitable for extended editing sessions.
DarkStudio Dark Dark theme inspired by professional DAW interfaces. Low-contrast for studio environments.
BroadcastPro Dark/teal Navy and teal broadcast studio theme matching the Mcaster1 ecosystem visual identity.

Creating a Custom Theme

# 1. Copy an existing theme as a starting point
cp -r themes/Default themes/MyCustomTheme

# 2. Edit theme.yaml to define your colors
#    Variables like {{bg_primary}}, {{accent_color}}, {{text_color}}
#    are substituted into style.qss at load time

# 3. Edit style.qss with Qt widget selectors
#    Use {{variable_name}} placeholders for colors

# 4. Select your theme in Preferences > Appearance
ℹ
Runtime switching. Themes can be switched at runtime without restarting. The ThemeEngine class watches the theme directory and reloads QSS when files change, making theme development interactive.

Platform Support

Mcaster1DAWCast targets all three major desktop platforms. The autotools build system and Qt 6 GUI framework provide cross-platform compatibility. Platform-specific code is isolated in the platform/ directory.

Platform Audio Backend Video HW Accel Status
macOS (arm64 + x86_64) PortAudio (CoreAudio) VideoToolbox Primary
Windows (x86_64) PortAudio (WASAPI / DirectSound) DXVA2 / D3D11VA Planned
Linux (x86_64) PortAudio (ALSA / PulseAudio / PipeWire) VAAPI / VDPAU Planned

Platform-Specific Files

  • platform/macos_audio.h / .mm — CoreAudio device discovery and AudioPipe integration (Objective-C++)
  • platform/macos_video.h / .mm — VideoToolbox hardware acceleration setup
  • platform/device_discovery.h / .mm — Audio/video device enumeration
  • platform/worker_pool.h / .cpp — Thread pool for parallel processing (cross-platform)
  • platform/compat.h — Cross-platform compatibility macros and type definitions

Ecosystem Integration

Mcaster1DAWCast integrates with the broader Mcaster1 broadcast stack. Each component is a standalone application that connects through standard audio interfaces, streaming protocols, and file formats.

Component Role DAWCast Integration
Mcaster1AudioPipe Virtual Audio Routing DAWCast outputs master bus to AudioPipe virtual devices for zero-latency routing to other applications (DSPEncoder, AMP).
Mcaster1DSPEncoder Broadcast Encoder DAWCast can route audio to DSPEncoder via AudioPipe for professional broadcast chain (EQ → AGC → encode → stream).
Mcaster1AMP Media Player AMP can output to AudioPipe; DAWCast can record from AudioPipe inputs, capturing AMP playback as source material.
Mcaster1DNAS Streaming Server DAWCast streams directly to DNAS using the built-in stream encoder. ICY metadata is pushed with track info.

Integration Flow

Mcaster1DAWCast (Production Studio) | +---> Mcaster1AudioPipe ---> Mcaster1DSPEncoder ---> Mcaster1DNAS ---> Listeners | (virtual routing) (broadcast encoding) (distribution) | +---> Built-in Encoder ---> Icecast2 / RTMP ---> Listeners / Viewers | (direct streaming) | +---> Podcast Export ---> RSS Feed ---> Apple Podcasts / Spotify / etc.
