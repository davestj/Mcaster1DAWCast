Mcaster1DAWCast

Multi-Channel DAW for Broadcasting

Welcome to the Mcaster1DAWCast installer. This application is a professional multi-channel digital audio workstation purpose-built for broadcast production, podcast editing, and live show preparation.

This installer will install Mcaster1DAWCast to:
/Applications/Mcaster1DAWCast.app

A copy will also be placed in ~/Mcaster1/Mcaster1DAWCast/ for portable use.

Key features:

  • Multi-channel timeline — unlimited audio and video tracks with non-destructive editing
  • Broadcast DSP chain — EQ, compressor, limiter, gate, and broadcast processing presets
  • Plugin hosting — VST3, Audio Unit, and CLAP plugin support
  • Export profiles — podcast MP3/AAC, broadcast WAV, YouTube 1080p, WebM VP9
  • Theme engine — BroadcastPro, DarkStudio, and Default themes included
  • CoreAudio + PortAudio — low-latency audio I/O with hardware monitoring
