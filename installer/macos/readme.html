What Gets Installed

ComponentLocationPurpose
Mcaster1DAWCast.app /Applications/ Main application — multi-channel DAW
Portable copy ~/Mcaster1/Mcaster1DAWCast/ Self-contained copy with config, data, and logs

Bundled Resources

ResourceDescription
ThemesBroadcastPro, DarkStudio, Default — QSS stylesheets with assets
DSP PresetsBroadcast Chain, Music Master, Podcast Voice, Spoken Word
Export ProfilesBroadcast WAV, Podcast MP3, Podcast AAC, YouTube 1080p, WebM VP9
DocumentationGetting started guide and feature reference
Note: This installer creates a portable application layout. All configuration, project data, and logs are stored inside the application directory. No files are written to ~/Library/Application Support/ or other system locations.

System Requirements

RequirementMinimum
macOS13.0 Ventura or later
ProcessorApple Silicon (M1/M2/M3/M4) or Intel x86_64
Disk Space~200 MB (plus project storage)
RAM8 GB (16 GB recommended for large sessions)
AudioCoreAudio-compatible audio interface

Dependencies

LibraryPurpose
Qt 6GUI framework, multimedia, and networking
FFmpegAudio/video codec support
PortAudioCross-platform audio I/O
libsndfileAudio file reading/writing
RubberbandTime-stretching and pitch-shifting
SQLite3Project and media database
libyamlConfiguration file parsing

All dependencies are bundled inside the application bundle. No additional software installation is required.

Uninstall

To remove Mcaster1DAWCast:

  1. Delete /Applications/Mcaster1DAWCast.app
  2. Delete ~/Mcaster1/Mcaster1DAWCast/ (includes config and project data)
